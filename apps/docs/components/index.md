# Components

| Component | Purpose |
| --- | --- |
| [`<XrScene>`](./XrScene) | Owns the XR session, input and frame loop. |
| [`<XrPanel>`](./XrPanel) | Floating surface, flex container. |
| [`<XrWindow>`](./XrWindow) | A panel you can pick up and move. |
| [`<XrDialog>`](./XrDialog) | Modal panel in front of the viewer, with a backdrop. |
| [`<XrBox>`](./XrBox) | Transparent flex container. |
| [`<XrText>`](./XrText) | Text in the theme's type scale. |
| [`<XrButton>`](./XrButton) | Button, three variants, three sizes, optional icon. |
| [`<XrIcon>`](./XrIcon) | Lucide or SVG icon. |
| [`<XrToggle>`](./XrToggle) | On/off switch. |
| [`<XrCheckbox>`](./XrCheckbox) | Checkbox, with an indeterminate state. |
| [`<XrRadioGroup>`](./XrRadioGroup) | One choice out of a few, all shown. |
| [`<XrSlider>`](./XrSlider) | Number in a range. |
| [`<XrProgress>`](./XrProgress) | Progress bar and spinner. |
| [`<XrTabs>`](./XrTabs) | Segmented tabs. |
| [`<XrList>`](./XrList) | Scrolling list with items. |
| [`<XrSelect>`](./XrSelect) | Dropdown with a floating list of options. |
| [`<XrTooltip>`](./XrTooltip) | Hover hint. |
| [`<XrTextField>`](./XrTextField) | Single-line text input. |
| [`<XrNumberInput>`](./XrNumberInput) | Number with − / + and a field. |
| [`<XrKeyboard>`](./XrKeyboard) | On-screen keyboard with voice input. |
| [`<XrThemeProvider>`](./XrThemeProvider) | Theme for a part of the scene. |
| [`<XrEnterButton>`](./XrEnterButton) | DOM button to enter VR or AR. |
