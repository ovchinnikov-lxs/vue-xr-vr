# <code>&lt;XrThemeProvider&gt;</code>

A theme for everything inside it: a whole `theme`, an `accent` colour, or both. See [Theming](/guide/theming).

## Usage

```vue
<XrThemeProvider accent="#f43f5e">
  <XrButton>Delete</XrButton>
</XrThemeProvider>
```
