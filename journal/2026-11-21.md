## Consumer smoke test, Codecov token (1eac8d1..c0f9f24)

### Done
- `pnpm test:smoke` (scripts/smoke-test.mjs + scripts/smoke-app): packs
  both packages, installs the tarballs with npm into a fresh Vite app,
  type-checks it (vue-tsc), builds it and opens it in Chromium. Fails on any
  page error, a render loop that does not run, or a font that does not load.
  Runs in the CI e2e job. Closes #14.
- Codecov upload now uses the `CODECOV_TOKEN` repo secret (Aleksandr added
  it after activating the repo on codecov.io). #51

### How
- The app imports from `vue-xr-ui` exactly like the README tells users to,
  so a broken `publishConfig.exports`, a missing file in `files` or broken
  d.ts shows up here before npm does.
- Playwright comes from the playground's `@playwright/test`; the app's own
  deps (vite, vue-tsc...) take the playground's versions.

### Learned
- A consumer tsconfig needs `skipLibCheck: true`: @vueuse/core's d.ts uses
  the `Temporal` namespace, which TS libs do not have yet.
- Headless Chromium requests `/favicon.ico` even with a `data:` icon link;
  the 404 is filtered out of the page errors.
- Codecov's OIDC upload failed until the repo was activated; with the
  token it uploads (the first run after the switch still had an empty
  token because the secret was added mid-run).

### Issues
- Closed: #14. #51 closes when the badge shows a number.
